# 雾港来电 · 午夜频率

## 安装

使用 Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8086 。可通过 PORT 环境变量修改端口。

## 自动恢复

调查过程（收集线索、选择方向、编辑笔记、播放暂停点）会定期形成自动恢复记录，独立于命名存档存储，不占用八个存档档位：

- 笔记编辑框中**未提交的草稿**会单独保存，恢复后回到原篇编辑状态；草稿不会提前覆盖正式笔记，也不会授予声音证据。
- 写入采用「当前记录 + 待提交记录」双槽：新记录先写入待提交槽并回读校验，通过后才替换当前槽，写入中断或容量不足都不会破坏上一份可用恢复点。
- 连续编辑在 1.5 秒合并窗口内合并写入，每 5 秒定时刷写；页面隐藏或关闭前会强制落盘，切换档案或开始新调查前先完成当前路线提交。
- 下次打开时可选择「恢复」或「丢弃」。容量不足时自动保存暂停并提示导出或清理建议，命名档案不会被自动删除。
- 损坏的恢复记录会被隔离（不影响命名档案），旧版恢复格式自动迁移。
